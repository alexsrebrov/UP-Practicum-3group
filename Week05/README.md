# Фунцкии

## Функции в математиката
В математиката, функциите са една от най-основните концепции. Те задават някакво **правило** f, което съпоставя на всеки елемент x от *множество A* точно един елемент y от *множество B*.

Ключовото за функциите в математиката е, че за *един и същи* параматър (*входни данни*), връщат винаги един и същи резултат.

## Функции в програмирането
Подобно на математиката, функциите са основен елемент на програмирането, *даващ ни възможност за многократна употреба на даден блок код*

Всяка функция представлява множество от операции, оформени така, че да представят обобщено дадено действие

Така, веднъж дефинирана фунцкията, можем да ѝ подаваме различни входни данни и да ни връща конкретен резултат - *напълно аналогично на математиката*

### Чисти фунцкии vs функции със страничен ефект
Дотук концептуално функциите в математиката и програмирането са едно и също нещо - някакво правило, което съпоставя резултат на входни данни. В програмирането обаче се въвежда едно много важно разграничение - т.нар. **чисти функции**

* ***Чистите функции*** са такива, които при едни и същи входни данни винаги ни връщат един и същи резултат и не променят нищо по външния свят

    **Пример**
    ```c++
    int add(int a, int b) {
        return a + b;
    }

    add(2, 3) // винаги ще връща 5
    ```

    Както можете да се досетите, функциите в математиката са чисти

* *"Нечистите"* фунцкии, или ***функции със страничен ефект*** са такива, които:
  * променят външния свят, т.е. имат *страничен ефект*
    
     **Пример**
    ```c++
    int total = 0;

    void add(int a) {
        total += a;
    }

    add(2); // total = 2, въпреки че е външна променлива за add
    add(7); // total = 9
    ```

  * връщат различен резултат при едни и същи входни данни 
  
    **Пример**
    ```c++
    double taxRate = 0.2;

    double addTax(double price) {
        return price * (1 + taxRate);
    }

    int main() {
        cout << addTax(100) << endl; // 120
        taxRate = 0.1;
        cout << addTax(100) << endl; // 110, а подадохме пак 100
        return 0;
    }
    ```

## Защо да използваме функции?
* Чрез функциите можем да разделим програмата ни на по-малки парчета код, които са по-лесни за тестване и модифициране
  
* Така също ***избягваме многократното повторение на един и съши код*** - веднъж създадена, на функцията се налага единствено да подадем различни входни данни

## Дефиниция и декларация
* Всяка функция си има **<сигнатура>**, която представлява *<тип резултат> <идентификатор>(<формални параметри>)*
  * *<тип резултат>* - за всяка функция *задължително* трябва да има тип на връщане - крайния резултат от всички операции в нея - `int`, `double`, `char` и т.н. Ако функцията не връща нищо се означава с `void`, понеже сме задължени да сложим някакъв return type
  * *<идентификатор>* - име на функцията. Опитваме се да даваме съществени имена на функциите, така че да се разбира какво правят само от идентификатора им
  
  * *<формални параметри>* - служат като "шаблони" какви параметри приема функцията (и съответно с които може да работи). Те могат да са *нула или повече* във формат *<тип> <идентификатор на параметър>*
    * на един параметър можем да зададем стойност по подразбиране. В такива ситуации, такива параметри трябва да са най-накрая на списъка с параметри

**Пример**
```c++
void f(int a, int b = 5) {...}
// void е типа на връщане
// f е идентификатора
// int a, int b = 5 са формалните параметри
// сега, при извикване на f, можем да изпуснем да подадем стойност на b

void g(int a, int b = 5, int c) {...}// грешка - c също трябва да има стойност по подразбиране
```
    
* **Декларацията** представлява *сигнатурата* на фунцкията, последвана от `;`
  * полезно е, понеже в някои ситуации искаме просто да кажем, че дадена фунцкия съществува (съответно и можем да я извикаме), а самата реализация ще опишем по късно
  * *декларацията* задължително трябва да предшества всяко извикване на функцията 

* **Дефиницята** представлява *декларация* + *тяло на фунцкията*

```c++
int sum(int a, int b); //декларация

int sum(int a, int b) {
    return a + b;
}  // дефиниция
```

## Извикане на фунцкия
* В началото на програмата се извиква главната `main()` функция. Езика `C++` е направен така, че да очаква именно тази функция като начало на програмата. Затова и ако ви се е случвало да имате няколко `main` функции, компилатора да ви дава съобщение за грешка.

* всяка функция може да се извиква многократно (вкл. и main, но не е препоръчотелно по обясними причини), което е *операция с много висок приоритет* (т.е. като извикаме функция, първо тя се изпълнява, и после продължява останалата програма)

* *<идентификатор>(<фактически параметри>)* - синтаксис за извикване
  * *<фактически параметри>* са реалните стойности, с които използваме функцията
  * те се приравянват на *<формалните параметри>* и при нужда се прави преобразуване на данни

* След като параметрите се подадат на функцията се **прави копие** на стойностите им в стековата рамка (за това ще учим по-късно, засега запомнете копието). Всички промени по параметрите и новосъздадени променливи са валидни само в *областта на видимост* на функцията и след приключването ѝ се изтриват

## Съставен блок и Област на видимост
* **Съставния блок** представлява обединението на няколко оператора в един. Дефинициите в рамките на блока остават в него. Един *съставен блок* се огражда с `{ }` (затова и навсякъде пишем къдрави скоби - всъщност ние сме правили такива съставни блокове + някаква бонус операция: `if`, `switch`, `for`, `while`, ...)

  * Можете да си представяте функциите като *именувани съставни блокове* (но не е формална дефиниция)

```
{
    <оператор 1>
    <оператор 2>
    ...
    <оператор n>
}
```

* **Областта на видимост** описва за даден съставен блок, какви променливи могат да се използват в него. Можем да използваме промнливите, дефинирани *вътре* в него, *извън* него (т.е. от по-външен блок), но не и от вложени в него блокове. За да стане по-ясно, ето следния пример:

```c++
{ // блок 1
    int a = 5;
    std::cout << a << std::endl;

    { // блок 2
        int b = 8;
        std::cout << a + b << std::endl; // няма проблем: a е дефинирано във външния блок

        std::cout << b + c << std::endl; // грешка: нямаме достъп до блок 3, понеже още дори не е създаден

        { // блок 3
            int c = 1;
        } // изтриване на данните от блок 3

        std::cout << b + c << std::endl; // грешка: след края на блок 3, c се изтрива и вече нямаме достъп до него
    } // изтриване на данните от блок 2
} // изтриване на данните от блок 1

```
