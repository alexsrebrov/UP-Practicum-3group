# Масиви

## Какво са масивите?

```cpp
int numbers[5] = {10, 20, 30, 40, 50};
```

```text
Index:     0       1       2       3       4
       +-------+-------+-------+-------+-------+
Value: |  10   |  20   |  30   |  40   |  50   |
       +-------+-------+-------+-------+-------+
```

```cpp
char chars[5] = {'a', 'b', 'c', 'd', 'e'};
```

```text
Index:     0        1        2        3        4
       +--------+--------+--------+--------+--------+
Value: |  'a'   |  'b'   |  'c'   |  'd'   |  'e'   |
       +--------+--------+--------+--------+--------+
```

```text
<type> <variable_name>[<size of array>] = {<values>}
```

Като стойности може да седи абсолютно всеки тип данни (просто и съствани)

## Какви са предимствата на масивите?

- Лесна обработка на данни – позволяват лесно обхождане, търсене, сортиране и промяна на елементите чрез цикли.
- По-малко променливи – вместо да декларираме отделна променлива за всяка стойност, използваме един масив.
- Съхранение на множество елементи – позволяват съхраняването на много стойности от един и същи тип под общо име

## Какво всъщност са масивите

Масивите са именувани "части от паметта", може да си ги представите като показатели към паметта

Какво ще се отпечата на конзолата при този код според вас?

```cpp
int arr1[3] = {1,2,3};
int arr2[3] = {1,2,3};
int arr3[3] = {1,2,4};

cout << arr[1] == arr[2] << arr[1] == arr[3] << arr[2] == arr[3];
```

!!!! Не сравнявайте масиви така arr1 == arr2

## Използване на масиви

1. Индексиране (взимане на елемент на определена позиция)
   ```cpp
    int array[3] = {1, 2, 3}
    cout << array[1];
   ```
1. Задаване на стойност на елементи на определен индекс
   ```cpp
   int array[3];
   array[2] = 12;
   cout << array[2];
   ```
1. Обхождане на масив
   ```cpp
   int array[3] = {1, 2, 3};
   for (int i = 0; i < 3; i++) {
       cout << array[i];
   }
   ```
1. Търсене в масив
   ```cpp
   int array[3] = {1, 2, 3};
   for (int i = 0; i < 3; i++) {
      if (array[1] == 2) {
            cout << "found";
      }
   }
   ```
1. Операция sizeof()
   Тази функция ни връща размера на типа данни и съответно при масивите ни връща дължината на масива \* sizeof(типа на масива)
   ```cpp
   int arr[4];
   cout << sizeof(arr); // Array size in bytes
   cout << sizeof(arr) / sizeof(int); // Array size in ints
   ```
1. Четене на масив от конзолата

   ```cpp
   int arr[10];
   for(int i = 0 ; i < 10; i++) {
       cin >> arr[i];
   }

   for(int i = 0 ; i < 10; i++) {
       cout << arr[i];
   }
   ```

1. Подаване на масиви като параметър на функции

   ```cpp
    void printArray(int arr[], int size) {
        for (int i = 0; i < size; i++) {
            std::cout << arr[i] << " ";
        }
   }
   ```

   - Функцията ще промени подадения масив, защото ние ще подадем "тази част от паметта"

1. Сортиране #Bonus
   ```cpp
   void bubbleSort(int arr[], int size) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
   }
   ```
